PROMPTWISE — STANDALONE WEBSITE

No React, Node.js, npm, Vite, or Python is required.

HOW TO RUN:
1. Extract this folder.
2. Double-click index.html.
3. It opens in your default browser.

Keep index.html, styles.css, and script.js together in the same folder.
The fonts are loaded from Google Fonts when internet is available; the site otherwise uses fallback fonts.
